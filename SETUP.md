# EdgeRunner AI Agent Creator — Setup Guide

## Architecture

```
┌──────────────────────────────────────────┐
│           Electron App (Frontend)        │
│   React + Tailwind + Framer Motion       │
│   • Agent Creator  • Chat  • Settings    │
└──────────────┬───────────────────────────┘
               │ HTTP / SSE (port 8765)
┌──────────────▼───────────────────────────┐
│         Python FastAPI Backend           │
│   • RAG Engine   • ChromaDB             │
│   • Document Processor (PDF/DOCX/MD/TXT) │
│   • Ollama / llama-server LLM client     │
└──────────────────────────────────────────┘
```

## Prerequisites

- **Python 3.11+**
- **Node.js 18+**
- **Ollama** running locally with:
  - `ollama pull nomic-embed-text` (required for embeddings)
  - Your chosen SLM, e.g. `ollama pull llama3`
- Or **llama-server** (`llama.cpp` HTTP server) on a configurable port

## Setup

### 1. Backend

```bash
cd backend
chmod +x setup.sh && ./setup.sh
```

### 2. Frontend

```bash
npm install
```

### 3. Start (Development)

```bash
# Terminal 1 — Backend
cd backend && source venv/bin/activate && python main.py

# Terminal 2 — Electron dev mode
npm run dev
```

### 4. Build for Distribution

```bash
npm run build:mac     # macOS .dmg
npm run build:win     # Windows .exe (NSIS)
```

## Creating Your First Agent

1. Click **New Agent**
2. Enter a name and (optionally) a description
3. Enter the Ollama model name (e.g. `llama3`) or browse to a `.gguf` file
4. Browse to your corpus folder (PDF, DOCX, TXT, MD supported)
5. Choose an accent color
6. Optionally customize the system prompt (auto-generated by default)
7. Click **Create & Index Knowledge Base**
8. Watch the real-time indexing progress
9. Click **Start chatting**

## How Citations Work

Every response shows:
- **Filename** of the source document
- **Page number** within that document
- **Excerpt** — the actual matched text passage
- **Match score** — cosine similarity percentage

## Data Storage

All agent configs and vector data are stored in `~/.edgerunner/`:
```
~/.edgerunner/
├── config.json          # App settings
├── agents/              # Agent configuration files
│   └── <uuid>.json
└── chromadb/            # Persistent vector store
```
